# Blueprints

Versioned JSON format the architect agent produces and builder agents execute (Phase 6).
Draft of format v1 (anchor, rotation, palette with block states, modules with dependencies, and
`set` / `fill` / `line` / `stairs` / `roof` / `layers` operations) is in
[docs/phase1-analysis.md](../docs/phase1-analysis.md#5-blueprint-v1-bozza).

The JSON Schema (`blueprint.schema.json`) and examples arrive in Phase 6.
